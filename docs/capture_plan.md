# 30분 캡처 시나리오 (내 기기 / 내 홈 Wi-Fi 트래픽만)

트래픽 패턴이 다양하게 나오도록 3가지 활동을 10분씩 섞는다.
캡처 시작 시각을 기준으로 아래 표를 채워서 `docs/activity_log.md` 에 남기면
3σ 이탈 구간의 원인 추정(어떤 활동 중이었는지)에 쓸 수 있다.

| 경과 시간 | 활동 | 기대되는 트래픽 특징 |
|---|---|---|
| 0 ~ 10분 | **웹 서핑**: 뉴스·블로그·쇼핑몰 등 서로 다른 사이트 10개 이상 방문, 페이지마다 링크 2~3개 클릭 | DNS 질의 多, 짧은 TLS 연결 다수, 처리량 낮음 |
| 10 ~ 20분 | **유튜브 스트리밍**: 1080p 이상 영상 연속 재생, 중간에 2~3번 다른 영상으로 이동 + 재생 위치 점프 | QUIC(UDP/443) 비중 ↑, 버스트형 다운로드, 처리량 중간 |
| 20 ~ 30분 | **파일 다운로드**: 500MB ~ 1GB 급 큰 파일 (예: Ubuntu ISO, VS Code 설치파일 여러 개 등) 동시에 1~2개 | 단일 TCP 연결 장기 지속, 처리량 최대, 재전송/RTT 변동 관찰 포인트 |

## 캡처 전 체크리스트
- [ ] 노트북이 **Wi-Fi 로만** 연결 (유선 빼기), VPN 끄기
- [ ] 클라우드 동기화(OneDrive 등) 일시 중지 → 배경 트래픽 최소화 (선택)
- [ ] 다른 기기 트래픽은 캡처되지 않음 (`-p` non-promiscuous + `host <내 IP>` 필터)
- [ ] 관리자 PowerShell 에서 `.\scripts\capture.ps1` 실행, 출력된 **시작 시각** 기록

## 캡처 후
```
python run_pipeline.py --pcap captures\home_30min_<날짜>.pcapng
```
`results/` 에 그래프 3장 + `summary.json` + `bins_1min.csv` 생성 (IP 마스킹됨).
raw pcap 과 `data/*_packets.csv` 는 `.gitignore` 로 커밋에서 제외된다.
